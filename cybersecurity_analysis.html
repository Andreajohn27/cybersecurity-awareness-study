Analysing Student's Online Habits and Cybersecurity Awareness¶

1. Problem Definition¶

With growing dependence on smartphones, social media platforms and public Wi-Fi networks, cybersecurity awareness among students has become an essential life skill. However, not every student who spends time online regularly follows recommended safety practices such as using unique passwords, enabling Two-Factor Authentication (2FA), or correctly identifying phishing attempts.

This project analyses the online habits and security practices of students and studies the factors related to their cybersecurity awareness. The project also uses simple machine learning models to predict whether a student is likely to have High or Low cybersecurity awareness based on their behaviour.

2. Objectives¶

  • To collect data about students' internet usage habits and cybersecurity practices.
  • To clean and prepare the survey data.
  • To study cybersecurity awareness patterns among students.
  • To analyse the collected data using exploratory and statistical methods.
  • To create useful charts and visualizations.
  • To find the factors affecting students' cybersecurity awareness.
  • To build a model that can predict a student's cybersecurity awareness level.
  • To check the performance of the model.
  • To give useful findings and suggestions based on the results.

3. Dataset Description¶

The dataset used in this project contains survey responses related to students' internet usage habits and cybersecurity practices.

Dataset Details

  • Dataset Name: Cybersecurity Awareness Dataset
  • Number of Records: 120
  • Number of Attributes: 15
  • Data Type: Mainly categorical/text data
  • Dataset Source: Survey data provided for the project (cybersecurity.csv)

The dataset contains information about respondents' age group, field of study, daily internet usage habits, device usage, password practices, 2FA usage, workshop attendance, and their knowledge of phishing, 2FA and password security.

Description of Attributes

The dataset contains attributes related to:

  • Age group and year of study of the respondent
  • Field of study of the respondent
  • Hours spent online per day and number of social media platforms used
  • Public Wi-Fi usage and the device used to access the internet
  • Password practices and use of Two-Factor Authentication (2FA)
  • Frequency of installing software/app updates
  • Attendance of a cybersecurity awareness workshop, seminar, course or training program
  • Knowledge questions related to phishing, 2FA and password security

Most of the attributes are categorical because the responses are given as text or selected options.

7. Feature Engineering¶

New features are created to convert the survey responses into a form that can be used for statistical analysis, visualization and model building. An Awareness_Score is calculated based on four knowledge questions covering phishing, 2FA and password security, and this score is used to derive the target variable, Awareness_Level.

In [15]:
# Create Awareness_Score based on 4 knowledge questions (1 point for each correct answer)
df["Awareness_Score"] = 0
df.loc[df["Q_Phishing"] == "A technique used to trick people into revealing sensitive information", "Awareness_Score"] += 1
df.loc[df["Q_2FA_Purpose"] == "To provide an additional layer of account security", "Awareness_Score"] += 1
df.loc[df["Q_Phishing_Message"] == "Verify the message through the organization's official website/app or another trusted channel", "Awareness_Score"] += 1
df.loc[df["Q_Strong_Password"] == "A long, unique password/passphrase that is not reused", "Awareness_Score"] += 1

Interpretation: Each correct answer to a knowledge question adds one point to the Awareness_Score, so the score ranges from 0 (no correct answers) to 4 (all correct answers), giving a simple numeric measure of a student's cybersecurity knowledge.

In [16]:
# Convert Hours_Online into numeric midpoint values
hours_map = {
    "Less than 2 hours": 1, "2–4 hours": 3, "4–6 hours": 5,
    "6–8 hours": 7, "More than 8 hours": 9
}
df["Hours_Online_Numeric"] = df["Hours_Online"].map(hours_map)

Interpretation: Since Hours_Online has a natural order, it is converted into an approximate numeric midpoint value so that it can be used in statistical analysis and visualizations.

In [17]:
# Convert Social_Media_Count into numeric midpoint values
social_map = {"0–1": 0.5, "2–3": 2.5, "4–5": 4.5, "More than 5": 6}
df["Social_Media_Numeric"] = df["Social_Media_Count"].map(social_map)

Interpretation: Social_Media_Count is converted the same way, allowing the number of platforms used to be treated as a numeric variable.

In [18]:
# Convert Attended_Workshop into 0/1
df["Workshop_Flag"] = df["Attended_Workshop"].map({"Yes": 1, "No": 0})

Interpretation: Workshop attendance is converted into a binary flag (1 = attended, 0 = did not attend) so it can be used directly as a numeric feature.

In [19]:
# Target variable: High (1) if Awareness_Score >= 3, else Low (0)
df["Awareness_Level"] = np.where(df["Awareness_Score"] >= 3, "High", "Low")

Interpretation: Students who answered at least 3 out of 4 knowledge questions correctly are labelled as High awareness, while the rest are labelled as Low awareness. This becomes the target variable for the classification model.

13. Findings¶

The major findings from the analysis are:

  • The dataset contains 120 survey responses related to students' online habits and cybersecurity practices.
  • Most respondents belong to the 18–20 age group (about 61.7%) and study Computer Science / Information Technology.
  • Smartphones are the most commonly used device to access the internet among students.
  • Cybersecurity awareness is fairly balanced in this sample: 68 out of 120 students (about 56.7%) show High awareness and 52 (about 43.3%) show Low awareness, based on their answers to knowledge questions on phishing, 2FA and password security.
  • Workshop attendance shows a strong positive association with awareness level — about 76.1% of students who attended a workshop have High awareness, compared to only about 28.6% of those who did not.
  • Awareness Score shows only a weak correlation with daily hours spent online and the number of social media platforms used, meaning awareness depends more on underlying knowledge (and workshop attendance) than on exposure time.
  • Students from Computer Science / Information Technology backgrounds have a notably higher average awareness score (about 3.08 out of 4) than students from other fields, especially compared to Arts / Humanities students (about 1.24 out of 4).
  • Logistic Regression (accuracy ≈0.88, F1 ≈0.89) clearly outperformed the Decision Tree Classifier (accuracy ≈0.67, F1 ≈0.73) at predicting a student's awareness level from behavioural and demographic features, though the small test set (24 records) means this result should be confirmed on more data.

14. Conclusion¶

This project analysed students' online habits and cybersecurity awareness using a complete data science process. The dataset was explored, cleaned and preprocessed before performing exploratory data analysis and statistical analysis. Different visualizations were used to understand device usage patterns, workshop attendance and cybersecurity knowledge among students.

An Awareness_Score was engineered from four knowledge questions and used to derive the target variable, Awareness_Level. Categorical variables required for machine learning were converted using dummy encoding. A Decision Tree Classifier was used to predict cybersecurity awareness level, and its performance was compared with a Logistic Regression model, with Logistic Regression achieving the stronger result on this dataset (accuracy ≈0.88 vs ≈0.67).

Overall, the project objectives were achieved by analysing the survey data, identifying key patterns in students' cybersecurity practices — most notably the strong link between workshop attendance and awareness level — and building baseline models to predict their awareness level.
